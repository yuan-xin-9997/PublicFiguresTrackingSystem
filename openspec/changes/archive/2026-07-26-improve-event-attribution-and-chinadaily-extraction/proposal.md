## Why

当前事件抽取会把“正文中被提及的人物”误当成动作或言论主体，导致习近平等人物的时间线混入“王毅会见……”一类无关事件；中国日报网文章抓取还可能把首页标题、导航和推荐内容拼入正文，进一步放大错误抽取。需要在入库前同时收紧人物归属证据和文章正文质量，恢复时间线的可信度与可核验性。

## What Changes

- 事件只有在证据片段能够证明目标人物是动作实施者、言论发表者或“其他”事实的明确主体时才允许归属；仅在背景、引用、指导思想、转述或其他人物的事件中被提及不得生成该人物事件。
- 本地规则抽取与外部模型结果使用同一套主体归属后置校验；无法确认主体的候选直接丢弃，不以低置信度事件代替。
- 对标题主体、句法主语、代词承接和动作/发言词邻近关系采用保守判定，覆盖“吉尔吉斯斯坦总统扎帕罗夫会见王毅”“王毅会见伊朗外长阿拉格齐”等反例。
- 为中国日报网及其子域增加正文边界清洗和文章有效性校验，移除首页、栏目、导航、页头、推荐阅读和页尾内容，拒绝把聚合页或异常长标题当作文章入库。
- 提供管理员可预览的存量数据修复流程：按新规则重新检查受影响材料与事件，只处理自动生成且未人工锁定的数据，执行结果进入任务日志和审计日志。
- 增加归属误判、中国日报正文污染、回退路径、幂等修复和权限边界的自动化测试，并同步 README、需求规格说明书、系统设计说明书及 Jenkins 验证项。
- 继续使用现有 FastAPI、Vue、SQLite 和集中 WebFetch 服务；不新增数据库或第三方抓取依赖，不把站点地址、凭证或环境参数硬编码进业务流程。
- 非目标：不尝试通用中文完整句法解析，不自动修改人工审核/锁定事件，不扩展新的事件类型，也不改变现有登录、普通用户页面权限和北京时间展示规则。

## Capabilities

### New Capabilities

- `event-subject-attribution`: 定义事件主体证据、提及与主体的区分、本地/外部抽取一致性，以及存量错误归属的安全修复行为。
- `article-content-quality`: 定义中国日报等新闻站点正文净化、聚合页拒绝、正文质量校验及采集任务可观测性。

### Modified Capabilities

无。现有 OpenSpec 主规格仅包含 `timeline-filter-layout`，本变更不修改其筛选布局需求。

## Impact

- 后端：`src/app/backend/extractor.py` 的人物主体判定和模型结果校验，`src/app/backend/collectors.py` 的中国日报清洗/文章拒绝规则，`src/app/backend/services.py` 与维护 API 的重分析和任务日志流程。
- 数据：继续使用 `src/data/app.sqlite3`；优先复用现有原始材料、事件证据、人工锁定、任务日志和审计表。若实现检查发现必须增加修复批次字段，只允许向后兼容的 SQLite 迁移并补充迁移测试。
- 外部服务：仍通过配置的集中 WebFetch 地址和 API Key 环境变量抓取；不绕过其缓存、限流、重试和 SSRF 保护。中国日报域名匹配是内容适配规则，不包含环境地址或凭证。
- API/UI：管理员可预览和执行修复；普通用户仅看到清理后的时间线结果，不获得新的写权限。现有认证、权限管理、系统配置和任务中心保持兼容，任务中心增加修复运行的计数与日志。
- 测试与交付：扩展后端单元/API/烟雾测试，检查前端回归、启动/停止/状态脚本和 Jenkinsfile；实现完成后更新 README、需求规格说明书和系统设计说明书。

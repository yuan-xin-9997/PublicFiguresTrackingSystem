# article-content-quality Specification

## Purpose

定义文章正文质量控制、站点专用清洗、统一抓取质量门槛、可观测性和存量污染数据清理要求，确保只有可信正文进入事件分析流程。

## Requirements

### Requirement: 中国日报文章正文必须去除页面框架

系统 SHALL 对 `chinadaily.com.cn` 及其子域的文章执行站点正文清洗，移除首页/频道标题、页头、导航、语言或客户端入口、分享字号控件、推荐阅读和页尾，只保留文章标题、元数据允许字段与正文事实。

#### Scenario: 首页标题位于文章标题之前
- **WHEN** WebFetch 返回的中国日报文章内容以网站首页标题和栏目导航开头，之后才出现“万山磅礴看主峰｜习近平谈亚太合作”及正文
- **THEN** 系统保存的 `content_text` 从文章标题或可信正文边界开始，且不包含前置首页标题和栏目导航

#### Scenario: 推荐内容位于正文之后
- **WHEN** 中国日报文章正文之后包含相关阅读、推荐阅读、编辑信息或版权区
- **THEN** 系统在最早可信页尾边界停止正文，不把推荐标题交给事件抽取器

#### Scenario: 正文包含真实引语
- **WHEN** 正文主体中包含人物的真实直接引语
- **THEN** 清洗保留该引语及其上下文，不因移除页面框架而删除正文证据

### Requirement: 聚合页和污染正文不得入库分析

系统 MUST 在文章入库和分析前校验规范 URL、标题、正文长度、导航标记密度及标题/正文重复污染；首页、栏目页、搜索结果页、专题聚合页或无法得到可信正文的页面 MUST 被拒绝。

#### Scenario: 中国日报首页被文章适配器返回
- **WHEN** `generic.article` 把中国日报首页或频道页返回为标题异常且导航标记密集的文章
- **THEN** 系统拒绝该文档，不创建原始材料或时间线事件，并记录明确原因

#### Scenario: 清洗后正文过短
- **WHEN** 页面框架移除后没有达到最小可信正文内容
- **THEN** 系统拒绝该候选，不以标题单独生成事件

#### Scenario: 合法中国日报文章
- **WHEN** 页面具有正常文章 URL、合理标题和足够的清洗后正文
- **THEN** 系统保存清洗后的原始材料并进入人物相关性与事件抽取流程

### Requirement: 集中抓取与本地降级使用相同质量门槛

系统 SHALL 继续通过配置的集中 WebFetch 服务抓取页面，并对 `generic.article` 成功结果和使用已抓取 artifact/body 的本地 HTML 清洗降级结果应用同一正文清洗与拒绝规则；系统 MUST 不因站点适配绕过集中服务、SSRF、缓存、限流或重试策略。

#### Scenario: generic.article 返回污染内容
- **WHEN** 集中服务成功提取文章但返回内容仍含中国日报页面框架
- **THEN** PFTS 在本地业务质量层完成清洗并重新校验后才允许入库

#### Scenario: 集中正文适配器失败
- **WHEN** `generic.article` 失败但集中抓取已返回可用 artifact 或 body
- **THEN** 系统只对该已抓取内容执行本地清洗降级，并应用相同文章有效性检查，不重新直连目标站点

#### Scenario: 集中服务不可用
- **WHEN** WebFetch 不可用且现有配置禁止直连降级
- **THEN** 采集任务明确失败并记录错误，不静默直连中国日报或其他目标站点

### Requirement: 站点适配不得污染其他来源

系统 MUST 将中国日报专用规则限制在规范化的中国日报域族；其他站点继续使用通用规则或各自既有适配，不得因标题中出现“中国日报”字样而误用站点规则。

#### Scenario: 其他站点转载中国日报内容
- **WHEN** 非中国日报域名的文章标题或正文提到“中国日报”
- **THEN** 系统不启用中国日报域名专用清洗，只执行该站点适用的通用或既有规则

#### Scenario: 中国日报子域
- **WHEN** 文章来自 `chinadaily.com.cn` 的合法子域
- **THEN** 系统使用同一域族的中国日报正文质量规则

### Requirement: 文章质量结果可观测

系统 MUST 在任务中心相关运行日志中记录扫描、抓取、清洗后接受、聚合页拒绝、正文不足拒绝和失败计数，并为被拒绝候选保留不含敏感配置的原因摘要。

#### Scenario: 采集包含接受和拒绝候选
- **WHEN** 一次中国日报来源采集同时发现合法文章与首页/栏目候选
- **THEN** 任务运行显示各类计数，合法文章正常分析，拒绝候选不生成事件

#### Scenario: 系统配置展示抓取参数
- **WHEN** 管理员查看生效配置
- **THEN** 系统继续展示 WebFetch 地址、超时、缓存和降级策略等非敏感配置，并对 API Key 环境变量及其他敏感值保持脱敏

### Requirement: 存量中国日报污染数据可预览清理

系统 SHALL 允许管理员使用 dry-run 识别不再满足正文质量要求的存量中国日报材料及其证据影响；执行清理时 MUST 保护人工锁定事件，并只删除因失去全部有效证据而成为孤立且未锁定的事件。

#### Scenario: 预览存量污染材料
- **WHEN** 管理员 dry-run 扫描已有中国日报材料
- **THEN** 系统返回将拒绝的材料、受影响证据与孤立事件计数及有限样例，不修改数据

#### Scenario: 执行存量清理
- **WHEN** 管理员确认执行且污染材料关联的自动事件没有其他有效证据
- **THEN** 系统在事务中清理材料关联和孤立自动事件，写入审计日志，并允许重复执行而不产生额外副作用
